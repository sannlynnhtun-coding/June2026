# Contributor Projects

This repository contains code samples for contributors to study and learn from. The project repositories listed below were created by contributors applying what they learned from these code samples. More projects will be added to this file over time.

## Projects

### [Book Store POS System](https://github.com/HninWuttYi-Dev/BookStorePOS)

- **Contributor:** Hnin Wutt Yi
- **GitHub username:** [HninWuttYi-Dev](https://github.com/HninWuttYi-Dev)

A web-based Point of Sale (POS) system for a bookstore that enables customers to browse and buy books easily while providing staff with tools to track inventory, process orders, and view sales metrics.

### [Online Class Management System](https://github.com/hlaingmyoaungdeveloper/OnlineClassManagementSystem)

- **Contributor:** Hlaing Myo Aung
- **GitHub username:** [hlaingmyoaungdeveloper](https://github.com/hlaingmyoaungdeveloper)

A layered .NET 8 Web API for managing online classes, student enrollments, capacity, schedules, subjects, users, and teaching plans using ASP.NET Core and Entity Framework Core.

### [SAMAT — Cyber Cafe & Gaming Lounge Management Platform](https://github.com/cctn214/Samat)

- **Contributor:** Soe Bala Win
- **GitHub username:** [cctn214](https://github.com/cctn214)

An all-in-one management platform for cyber cafés, esports arenas, and gaming lounges, featuring terminal and session tracking, prepaid and postpaid billing, memberships, a café POS, and order fulfillment.

### [BrightSteps Tracker — Childcare Daily Care Tracking System](https://github.com/htet-dev/BrightStepsTracker)

- **Contributor:** Htet Htet Hlaing
- **GitHub username:** [htet-dev](https://github.com/htet-dev)

A web-based childcare management system that helps educators manage children and track daily care activities such as meals, nappy changes, and nap times using ASP.NET Core MVC, Web API, C#, and SQL Server.

### [Hotel Booking Management System](https://github.com/khinshwedeveloper/Project-Ks7)

- **Contributor:** Khin Shwe
- **GitHub username:** [khinshwedeveloper](https://github.com/khinshwedeveloper)

A web-based ASP.NET Core MVC system that helps hotel staff manage customers, rooms, room types, bookings, payments, services, check-ins, check-outs, reports, dashboard notifications, and real-time updates.

### [YourRecipes](https://github.com/devsanlphyo/yourrecipes)

- **Contributor:** San Linn Phyo
- **GitHub username:** [devsanlphyo](https://github.com/devsanlphyo)

A recipe-sharing website where users can browse recipes, save favorites, and publish their own recipes, built with a Next.js frontend and an ASP.NET Core Web API backend.

### [Shared Expense Tracker App](https://github.com/Tsukuna/SharedExpenseTrackerApp)

- **Contributor:** Htet Min Lu
- **GitHub username:** [Tsukuna](https://github.com/Tsukuna)

An application for recording and managing shared expenses, helping users keep track of costs shared with other people.
